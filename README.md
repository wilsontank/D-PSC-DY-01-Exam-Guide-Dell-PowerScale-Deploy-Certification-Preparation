## D-PSC-DY-01 Exam Topics at a Glance

Dell divides the exam into four main areas. 

| Exam Domain | Weight |
|---|---:|
| Install Nodes and Create Cluster | 14% |
| Configure Cluster and Nodes Post Installation | 62% |
| Monitor and Troubleshoot Cluster Environment | 12% |
| Enable Data Protection | 12% |

The most important takeaway is obvious: **post-installation configuration dominates the exam at 62%**. If your study time is limited, this should be your highest priority.

## 1. Install Nodes and Create Cluster — 14%

This domain focuses on the initial deployment of a PowerScale environment.

Candidates should understand how to:

- Apply backend- andfrontend-cabling.

- Remove, reformat, and reimage a node.

## 2. Configure Cluster and Nodes Post Installation — 62%

This is by far the largest section of the exam.

Candidates should know how to configure:

- Configure protocol settings.
- Align the necessary components to set up SmartConnect on aPowerScalecluster.
- Configure software modules.
- Configure Authentication Providers along with Access Zones.

## 3. Monitor and Troubleshoot Cluster Environment — 12%

This domain focuses on ongoing operational health after deployment.

Candidates should understand how to:
- Monitor andoptimizesystem performance.
- InstallInsightIQto discover andmonitorthePowerScalecluster.
- Perform ClusterHealthCheckand Event/Alert Notifications.
- Perform basic troubleshooting in the cluster environment.
- Demonstrate job engine best practices and considerations.

## 4. Enable Data Protection — 12%

This domain focuses on protecting data and integrating antivirus capabilities.

Candidates should understand how to:

- Configure data protection.
- Install and configure Antivirus (CAVA/ICAP).
